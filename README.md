# 코테 복습 노트

틀린 코딩테스트 문제를 넣으면 AI가 한 장짜리 오답노트를 만들고, 1일·3일·7일·21일 간격으로 다시 풀게 해 주는 개인용 복습 도구.

현재 상태: **1차 버전(혼자 쓰는 로컬 도구)**. 동작은 확인했고, 실제 사용 기록은 아직 없다.

## 왜 만들었나

프로그래머스에서 헷갈리거나 틀린 문제를 따로 저장해 두지만 다시 보지 않아 계속 쌓였다. 영어 단어 앱이 틀린 단어를 주기적으로 다시 보여 주듯, 코딩테스트 문제도 그렇게 할 수 없을까 하는 데서 시작했다.

기존 도구를 조사해 보니 LeetCode용 간격 반복 도구는 여럿 있지만 대부분 "언제 다시 풀지 알려 주는" 데서 끝난다. 저장만 하고 손이 안 가는 원인은 오답노트를 쓰기 귀찮다는 것이라고 보고, **노트를 AI가 대신 써 주는 것**을 핵심으로 잡았다.

확인하려는 가설: AI가 노트를 만들어 주면 실제로 복습을 하게 되는가.

## 동작

1. 문제 링크, 제목, 문제 설명, 제출 코드, 제출 결과를 입력한다.
2. 모델이 노트를 만든다. 항목은 어디서 틀렸나 / 수정한 코드 / 핵심 아이디어 / 다른 풀이 방법 / 다음에 떠올릴 신호.
3. 복습일이 되면 "오늘 복습"에 뜬다. 노트는 접혀 있어서 먼저 다시 풀어 보게 된다.
4. 맞히면 다음 간격으로 넘어가고, 틀리면 1일 간격으로 돌아간다.

## 실행

Python 3.9 이상과 [Claude Code](https://claude.com/claude-code)가 필요하다. 추가로 설치할 패키지는 없다.

```bash
python3 server.py
```

브라우저에서 `http://127.0.0.1:8765`를 연다.

## 설계에서 정한 것

- **모델은 Claude Haiku.** 버그를 숨긴 문제 4개로 Haiku, Sonnet, Opus를 비교했고 원인 진단은 세 모델이 같았다. 과정과 한계는 [experiments/README.md](experiments/README.md)에 있다.
- **모델 호출은 Claude Code 명령줄로.** 혼자 쓰는 단계에서는 구독 안에서 돌아가 추가 비용이 없다. 여러 사람이 쓰는 웹 서비스로 만들려면 API로 바꿔야 한다.
- **문제 지문은 저장하지 않는다.** 지문은 출제 사이트의 저작물이라 노트를 만들 때만 읽는다. 저장하는 것은 링크, 제목, 내 코드, 메모, 노트다.
- **특정 사이트에 묶이지 않는다.** 링크만 있으면 어느 사이트 문제든 등록된다.
- **연습 문제 전용.** 실제 시험이나 기업 코딩테스트 도중에는 쓰지 않는다.

## 파일

| 파일 | 역할 |
|---|---|
| `server.py` | 저장(SQLite), 복습 일정 계산, 모델 호출 |
| `index.html` | 화면 |
| `prompt.md` | 모델에게 주는 지시문 |
| `config.json` | 모델 이름, 복습 간격 |
| `experiments/` | 모델 비교 실험의 문제, 채점 코드, 결과 |

## 아직 안 된 것

- 실제 문제로 2주 이상 써 본 기록
- 자동 테스트
- 틀린 직후 자동 등록 (지금은 직접 붙여 넣어야 한다)
- 공개 서비스로 전환할 때 필요한 것: 출제 사이트 이용약관 확인, API 전환과 비용 관리, 코드가 외부 모델로 전송된다는 고지

## 만든 방식

Claude Code와 대화하며 만들었다. 문제 정의, 기능 범위, 모델 선택 기준은 직접 정했고, 조사와 코드 작성, 실험 실행은 AI가 했다.
